Statistik Indonesia — a national statistics portal for Indonesia: population, economy, employment, education, health and province comparisons, with real BPS figures labelled with source and year, hand-built SVG charts, and a working year selector, province filter and search. Runs offline in a browser on desktop and phone. Built by an AI agent for make.fun's "Make the best national statistics site" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
